# Rapport de shift

Petite web app mobile pour préparer le rapport de shift du soir et l'envoyer sur WhatsApp.

- Saisie rapide : tâches, astreinte, nettoyage du lendemain, petit-déjeuner, précisions
- Bouton **Lancer Claude** : Claude lit le planning Asterio (via Claude in Chrome sur le Mac) et renvoie le rapport
- Bouton **Coller la réponse** : remplit l'app automatiquement
- Envoi WhatsApp en un appui

L'adresse Asterio se règle dans l'app et reste enregistrée sur l'appareil (elle n'est pas dans ce dépôt).
